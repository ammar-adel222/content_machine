# User Data Deletion Instructions

**Application:** The Byte Canvas (Content Machine)  
**Last updated:** November 26, 2026

## 1. Scope Note
**The Byte Canvas (Content Machine)** is a single-operator publishing utility used exclusively by the account owner to publish Reels/videos and inspect aggregate post metrics on owned Facebook and Instagram channels. The application does not maintain public user accounts or store third-party personal user data on remote servers.

## 2. Option 1 — Remove App Access via Facebook / Meta Settings
1. Open your Facebook account's **Settings & Privacy** -> **Settings**.
2. Navigate to **Apps and Websites** (or **Business Integrations** for Page-linked tools).
3. Locate **The Byte Canvas** / **Content Machine** in the active list.
4. Click **Remove** to revoke all granted tokens and permissions.

## 3. Option 2 — Direct Deletion Request
To request confirmation or removal of any locally cached API tokens, upload receipts, or aggregate channel logs associated with an account:
- Email `ammar2006326@gmail.com` with the subject line **Data Deletion Request**, or
- Open a request at https://github.com/ammar-adel222/content_machine/issues.

All valid deletion requests are processed and confirmed within **48–72 hours**.
